Key Features
- Dark Mode & Light Mode Toggle: Interactive dark and light theme switcher paired with a subtle dot-grid background pattern.
- Sticky Navigation Header: Top navigation bar that stays fixed while scrolling with a frosted backdrop-blur effect.
- Two-Column Hero Section: Introduction layout featuring a blinking terminal cursor (_) animation and an interactive profile picture frame.
- Bento Grid About Section: Clean two-column layout dividing personal details into Bio and Status cards.
- Interactive Mini-Game (Number Guessing Game): Built-in random number guessing game (1–5) directly inside the featured project card without page reloads.
- One-Click Copy Email: Automatically copies the email address to the clipboard with instant confirmation feedback.
